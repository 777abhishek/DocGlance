# DocGlance 1.0.0

The first public release of DocGlance, a native Windows viewer for common
documents, spreadsheets, presentations, images, and text files.

## Highlights

- View PDF, DOCX, PPTX, and XLSX files, plus supported image, Markdown, text,
  and source-code formats.
- Search document content and navigate pages, slides, and workbook sheets.
- Add annotations to PDF documents.
- Translate selected text offline after downloading translation models.
- Open files through Windows file pickers and integrate with Windows file
  associations.

## Requirements

- 64-bit Windows 10 version 2004 (build 19041) or later.
- Internet access is needed to download offline translation models.

## Installation

Download `DocGlance-1.0.0-Setup-x64.exe` from this GitHub Release and run it.
The installer is unsigned; Windows may display a SmartScreen warning.
